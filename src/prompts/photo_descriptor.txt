- hero_name
- age
- gender (may not match the photo perfectly; do not assume sensitive traits)
- language (book language)
- photo_url (a real image URL)

Produce a compact, reusable "character fingerprint" that helps keep the child's appearance consistent across illustrations.

IMPORTANT:
- Return ONLY valid JSON
- Do NOT identify real people
- Do NOT guess sensitive attributes (ethnicity, religion, etc.)
- Focus on visible, non-sensitive, non-identifying physical traits and clothing/accessories
- If something is unclear, say "unknown" rather than guessing
- Keep it short and very usable for image prompts

Return JSON exactly in this shape:

{
  "photo_descriptor": {
    "character_fingerprint": "1-3 short paragraphs in English describing the child’s visible traits (hair, eyes, face shape, skin tone using neutral wording, posture, typical expression), plus any consistent clothing/accessory details if visible. Avoid unique identifiers.",
    "do_not_change": [
      "List 6-10 bullet-like strings of the most important traits to keep consistent across pages (e.g., hair length/color, hairstyle, eye color, glasses yes/no, signature accessory visibility, general face shape)."
    ],
    "notes": {
      "quality": "good|average|poor",
      "issues": ["optional list such as blur, backlit, partial face, etc."]
    }
  }
}
