Installer Calitiki sur cet iPhone

  1. Touchez le bouton Partager de Safari : le carré avec une flèche vers le haut.
  2. Faites défiler le menu, puis choisissez « Sur l’écran d’accueil ».
  3. Touchez « Ajouter ». L’icône Calitiki ouvrira ensuite directement votre dernier livre.
