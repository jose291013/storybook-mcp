# Bibliothèque d'exemples

Les chemins et prompts attendus sont documentés dans `docs/visual-example-prompts.md`.

Le configurateur affiche automatiquement les fichiers WebP dès qu'ils sont ajoutés dans :

- `hero/hero-cover.webp`
- `universes/*.webp`
- `styles/*.webp`

Le style `paper_cut` conserve provisoirement son aperçu graphique léger jusqu'à l'ajout de `styles/paper_cut.webp`.

En leur absence, l'interface conserve ses aperçus graphiques légers comme solution de secours.
